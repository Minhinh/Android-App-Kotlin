# Climber Score Tracker App

## 📱 Overview

This Android application, developed for the **COS30017 - Software Development for Mobile Devices** unit at **Swinburne University of Technology**, is designed to track a climber's scoring process throughout a session. The app provides real-time interaction with a user-friendly interface, supports multiple screen orientations, includes a session timer, and supports bilingual display.

This project is part of **Assignment 1 – Leading the Way** and was completed in **Semester 2, 2024**.

---

## 🚀 Features

- ✅ Real-time scoring system for climbers
- 🔄 Responsive UI supporting **portrait and landscape** orientations
- 🌍 Multi-language support (English + one additional language)
- ⏱ Session **timer** with reset function
- 🎨 Visually-enhanced design with **dynamic backgrounds**, themed buttons, and scoring color indicators
- 💾 Maintains score and timer on **orientation change** using `onSaveInstanceState()`
- 📊 Organized codebase using **MVVM pattern** (with `ScoreViewModel`)
- 🧪 Thoroughly tested on modern Android emulator (Pixel Fold 8)
